# Pyno's Squish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Pyno's Squish, a Windows desktop app that compresses one video at a time for social media using presets (platform or size limit) that the user can customize and save, with a before/after preview and GPU encoding.

**Architecture:** Electron app built with electron-vite. A pure planning module in `src/shared/` turns video info plus user settings into encode parameters, size estimate, warning and "what changes" rows. The renderer runs it on every change, and the main process runs it again to build FFmpeg arguments. The main process owns everything with side effects: ffprobe/ffmpeg child processes, encoder detection, preview files, preset storage. It exposes them to a sandboxed React renderer through one typed preload API.

**Tech Stack:** Electron 44, electron-vite 5, Vite 7, React 19, TypeScript 5.9, Motion 13 (`motion/react`), Zustand 5, Vitest 5, electron-builder 26, bundled FFmpeg (BtbN GPL win64 build), Fontsource fonts.

**Spec:** `docs/superpowers/specs/2026-09-24-squish-design.md` (read it first; the mockups linked in its header show every screen).

## Global Constraints

- Windows 10/11 x64 only. No macOS code paths.
- UI copy is English. Brand name in UI copy is always `Pyno's Squish` (with apostrophe). Identifiers and file names use `pynos-squish`.
- No network access except `shell.openExternal` to the two allow-listed URLs in `src/shared/links.ts`.
- No telemetry, no accounts, no license checks.
- Output: MP4, video H.264 or H.265 (`-tag:v hvc1`), audio AAC, `-movflags +faststart`. Output path `<name>_squish.mp4` next to the source, then `<name>_squish (2).mp4` and so on. Never overwrite.
- Squish never upscales and never lowers resolution, frame rate or audio unless the user picked a lower option. "Best" = source value, capped at short side 2160, 60 fps, AAC 320k.
- Size limit math: 1 MB = 1,000,000 bytes, budget = limit × 0.97, minimum video bitrate 50 kbit/s, the result must be ≤ limit.
- Renderer security: `contextIsolation: true`, `nodeIntegration: false`, `sandbox: true`. The renderer only uses `window.squish`.
- Styling uses the Pyno Nacht tokens (Task 10). Motion uses the three springs from the Pyno system: snappy 500/32, smooth 260/28, bouncy 380/18, with `MotionConfig reducedMotion="user"`.
- No em dashes in UI copy (Pyno voice rule).
- Before release, Pyno must confirm `PROMO_URL` in `src/shared/links.ts` (Task 16, Step 5).

## Review Focus

1. **Phone videos with rotation metadata** (stored 1920×1080 with a rotate=90 side-data flag). The output must come out portrait 1080×1920, and "1080p" must mean the short side. Pinned in Task 4.
2. **Auto mode producing a file larger than the source** (an already well-compressed source). The Done screen must not claim "smaller". Pinned in Task 9 (`doneSummary`).
3. **Paths with spaces, apostrophes and non-ASCII** (`C:\Users\Lou\Videos\Pyno's clip ä.mp4`). Encoding must work, including x265 2-pass stats files. Pinned in Task 7 (integration test).
4. **Very short clips (under 5 s) and odd dimensions** (e.g. 1081×1921 screen recordings). The preview window must clamp and dimensions must be even. Pinned in Task 2 and Task 8.
5. **Cancelling during pass 1 of a 2-pass encode.** No partial MP4 and no pass-log files may be left behind. Pinned in Task 7.

```ts
import { win32 } from 'node:path'

export interface PathEnv { packaged: boolean; resourcesPath: string; appPath: string }

export function binPath(name: 'ffmpeg' | 'ffprobe', env: PathEnv): string {
  const base = env.packaged ? env.resourcesPath : win32.join(env.appPath, 'resources')
  return win32.join(base, 'bin', `${name}.exe`)
}
```

- [ ] **Step 8: Write `scripts/fetch-ffmpeg.mjs`**

The script downloads the newest BtbN release build (`ffmpeg-nX.Y-latest-win64-gpl-X.Y.zip`; it includes libx264, libx265, NVENC, AMF, QSV and zimg) and copies `ffmpeg.exe`, `ffprobe.exe` and `LICENSE.txt` into `resources/bin`.
```js
import { mkdir, readdir, copyFile, rm, writeFile } from 'node:fs/promises'
import { join } from 'node:path'
import { execFileSync } from 'node:child_process'
import { tmpdir } from 'node:os'

const api = 'https://api.github.com/repos/BtbN/FFmpeg-Builds/releases/tags/latest'
const rel = await (await fetch(api, { headers: { 'User-Agent': 'pynos-squish' } })).json()
const re = /^ffmpeg-n(\d+)\.(\d+)-latest-win64-gpl-\d+\.\d+\.zip$/
const asset = rel.assets
  .filter((a) => re.test(a.name))
  .sort((a, b) => {
    const [, am, an] = a.name.match(re); const [, bm, bn] = b.name.match(re)
    return (Number(bm) - Number(am)) || (Number(bn) - Number(an))
  })[0]
if (!asset) throw new Error('No win64 gpl release asset found')
console.log('Downloading', asset.name)
const work = join(tmpdir(), `squish-ffmpeg-${Date.now()}`)
await mkdir(work, { recursive: true })
const zip = join(work, asset.name)
await writeFile(zip, Buffer.from(await (await fetch(asset.browser_download_url)).arrayBuffer()))
execFileSync('tar', ['-xf', zip, '-C', work])
const dir = (await readdir(work, { withFileTypes: true })).find((d) => d.isDirectory()).name
const out = join(process.cwd(), 'resources', 'bin')
await mkdir(out, { recursive: true })
for (const f of ['ffmpeg.exe', 'ffprobe.exe']) await copyFile(join(work, dir, 'bin', f), join(out, f))
await copyFile(join(work, dir, 'LICENSE.txt'), join(out, 'LICENSE.txt'))
await rm(work, { recursive: true, force: true })
console.log('FFmpeg ready in', out)
```

- [ ] **Step 4: Implement `src/shared/format.ts`**

```ts
export function formatBytes(bytes: number): string {
  return bytes >= 1e9 ? `${(bytes / 1e9).toFixed(2)} GB` : `${(bytes / 1e6).toFixed(1)} MB`
}

export function resLabel(shortSide: number): string {
  return shortSide >= 2160 ? '4K' : `${shortSide}p`
}

export function codecLabel(name: string): string {
  const map: Record<string, string> = { h264: 'H.264', hevc: 'H.265', h265: 'H.265', av1: 'AV1', vp9: 'VP9' }
  return map[name] ?? name.toUpperCase()
}

export function formatFps(fps: number): string {
  return `${Number(fps.toFixed(2))} fps`
}
```

```ts
import { codecLabel, formatFps, resLabel } from './format'
import type {
  AudioChoice, Change, Codec, EncoderChoice, EncoderId, FpsChoice, Plan, PlanMode, PlanWarning, ResChoice, Settings, VideoInfo
} from './types'

export const MAX_SHORT_SIDE = 2160
export const MAX_FPS = 60
export const SIZE_MARGIN = 0.97
export const MIN_VIDEO_KBPS = 50
export const ENCODER_ORDER: EncoderId[] = ['nvenc', 'amf', 'qsv', 'cpu']
export const AUDIO_KBPS: Record<AudioChoice, number> = { best: 320, high: 192, standard: 128 }
export const QUALITY_BPP: Record<Codec, number> = { h264: 0.1, h265: 0.06 }
export const WARN_BPP: Record<Codec, number> = { h264: 0.035, h265: 0.022 }
const RES_SHORT: Record<Exclude<ResChoice, 'best'>, number> = { '1440': 1440, '1080': 1080, '720': 720 }
const LOWER_RES: Exclude<ResChoice, 'best'>[] = ['1440', '1080', '720']

const even = (n: number): number => Math.max(2, Math.round(n / 2) * 2)
const srcShort = (info: VideoInfo): number => Math.min(info.width, info.height)

export function outputDims(info: VideoInfo, res: ResChoice): { width: number; height: number } {
  const src = srcShort(info)
  const cap = res === 'best' ? MAX_SHORT_SIDE : RES_SHORT[res]
  const target = Math.min(src, cap)
  const k = target / src
  return { width: even(info.width * k), height: even(info.height * k) }
}

export function disabledRes(info: VideoInfo): ResChoice[] {
  return LOWER_RES.filter((r) => RES_SHORT[r] > srcShort(info))
}

export function disabledFps(info: VideoInfo): FpsChoice[] {
  return info.fps < 59.5 ? ['60'] : []
}

function outputFps(info: VideoInfo, fps: FpsChoice): { fps: number; expr: string } {
  const cap = fps === '30' ? 30 : MAX_FPS
  if (info.fps <= cap + 0.01) return { fps: info.fps, expr: info.fpsFraction.replace(/\/1$/, '') }
  return { fps: cap, expr: String(cap) }
}

function outputAudio(info: VideoInfo, audio: AudioChoice): number | null {
  if (!info.hasAudio) return null
  const src = info.audioKbps > 0 ? info.audioKbps : Infinity
  return Math.min(AUDIO_KBPS[audio], src)
}

function resolveEncoder(choice: EncoderChoice, available: EncoderId[]): EncoderId {
  if (choice !== 'auto') return available.includes(choice) ? choice : 'cpu'
  return ENCODER_ORDER.find((e) => available.includes(e)) ?? 'cpu'
}

function warningFor(
  info: VideoInfo, s: Settings, width: number, height: number, fps: number, videoKbps: number
): PlanWarning | null {
  if (s.maxMB === null) return null
  const thr = WARN_BPP[s.codec]
  const bpp = (w: number, h: number): number => (videoKbps * 1000) / (w * h * fps)
  if (bpp(width, height) >= thr) return null
  const current = Math.min(width, height)
  const lower = LOWER_RES.filter((r) => RES_SHORT[r] < current)
  if (lower.length === 0) return null
  const fit = lower.find((r) => {
    const d = outputDims(info, r)
    return bpp(d.width, d.height) >= thr
  })
  const suggest = fit ?? '720'
  return { text: `${s.maxMB} MB is tight for ${resLabel(current)}. ${resLabel(RES_SHORT[suggest])} will look cleaner.`, suggest }
}

function changesFor(info: VideoInfo, p: Omit<Plan, 'changes'>): Change[] {
  const rows: Change[] = []
  const sameDims = p.width === even(info.width) && p.height === even(info.height)
  rows.push({ label: 'RESOLUTION', from: `${info.width}×${info.height}`, to: sameDims ? 'kept' : `${p.width}×${p.height}` })
  rows.push({ label: 'FRAME RATE', from: formatFps(info.fps), to: Math.abs(p.fps - info.fps) < 0.01 ? 'kept' : formatFps(p.fps) })
  if (p.audioKbps !== null) {
    const from = info.audioKbps > 0 ? `${codecLabel(info.audioCodec)} ${info.audioKbps}k` : codecLabel(info.audioCodec)
    const kept = info.audioCodec === 'aac' && p.audioKbps >= info.audioKbps
    rows.push({ label: 'AUDIO', from, to: kept ? 'kept' : `AAC ${p.audioKbps}k` })
  }
  const srcM = info.videoKbps > 0 ? ` ${(info.videoKbps / 1000).toFixed(0)}M` : ''
  rows.push({ label: 'VIDEO', from: `${codecLabel(info.videoCodec)}${srcM}`, to: `${codecLabel(p.codec)} ${(p.videoKbps / 1000).toFixed(1)}M` })
  if (info.hdr) rows.push({ label: 'HDR', from: 'HDR', to: 'SDR' })
  return rows
}

export function buildPlan(
  info: VideoInfo, s: Settings, available: EncoderId[], override: { encoder?: EncoderId; videoKbps?: number } = {}
): Plan {
  const { width, height } = outputDims(info, s.res)
  const { fps, expr } = outputFps(info, s.fps)
  const audioKbps = outputAudio(info, s.audio)
  const encoder = override.encoder ?? resolveEncoder(s.encoder, available)
  const a = audioKbps ?? 0
  const dur = info.durationSec

  let mode: PlanMode
  let videoKbps: number
  if (s.maxMB !== null) {
    mode = 'target'
    const budget = s.maxMB * 1e6 * SIZE_MARGIN
    videoKbps = override.videoKbps ?? Math.max(MIN_VIDEO_KBPS, Math.floor((budget * 8) / dur / 1000 - a))
  } else if (s.bitrateKbps !== null) {
    mode = 'bitrate'
    videoKbps = override.videoKbps ?? s.bitrateKbps
  } else {
    mode = 'quality'
    videoKbps = Math.round((width * height * fps * QUALITY_BPP[s.codec]) / 1000)
  }

  let estimateBytes = Math.round(((videoKbps + a) * 1000 * dur) / 8)
  if (s.maxMB !== null) estimateBytes = Math.min(estimateBytes, Math.round(s.maxMB * 1e6 * SIZE_MARGIN))

  const base = {
    mode, encoder, codec: s.codec, width, height, fps, fpsExpr: expr, audioKbps, videoKbps,
    passes: (encoder === 'cpu' && mode === 'target' ? 2 : 1) as 1 | 2,
    estimateBytes,
    warning: warningFor(info, s, width, height, fps, videoKbps)
  }
  return { ...base, changes: changesFor(info, base) }
}
```

```ts
import type { Codec, EncoderId, Plan, VideoInfo } from './types'

export const PASSLOG_NAME = 'squish2pass'

export const TONEMAP_CHAIN = [
  'zscale=t=linear:npl=100', 'format=gbrpf32le', 'zscale=p=bt709',
  'tonemap=tonemap=hable:desat=0', 'zscale=t=bt709:m=bt709:r=tv'
]

export interface ArgsOptions {
  input: string
  output: string
  pass?: 1 | 2
  passLogName?: string
  sample?: { startSec: number; durationSec: number }
}

const NAMES: Record<Codec, Record<EncoderId, string>> = {
  h264: { cpu: 'libx264', nvenc: 'h264_nvenc', amf: 'h264_amf', qsv: 'h264_qsv' },
  h265: { cpu: 'libx265', nvenc: 'hevc_nvenc', amf: 'hevc_amf', qsv: 'hevc_qsv' }
}
const QUALITY: Record<EncoderId, Record<Codec, string>> = {
  cpu: { h264: '20', h265: '23' }, nvenc: { h264: '23', h265: '25' },
  amf: { h264: '23', h265: '25' }, qsv: { h264: '23', h265: '25' }
}

export function videoFilter(info: VideoInfo, plan: Plan): string {
  const parts: string[] = []
  if (info.hdr) parts.push(...TONEMAP_CHAIN)
  if (plan.width !== info.width || plan.height !== info.height) parts.push(`scale=${plan.width}:${plan.height}:flags=lanczos`)
  parts.push(`fps=${plan.fpsExpr}`)
  parts.push(`format=${plan.encoder === 'qsv' ? 'nv12' : 'yuv420p'}`)
  return parts.join(',')
}

function rateArgs(plan: Plan): string[] {
  const v = plan.videoKbps
  return ['-b:v', `${v}k`, '-maxrate', `${Math.round(v * 1.5)}k`, '-bufsize', `${v * 2}k`]
}

function encoderArgs(plan: Plan, o: ArgsOptions): string[] {
  const name = NAMES[plan.codec][plan.encoder]
  const q = QUALITY[plan.encoder][plan.codec]
  const quality = plan.mode === 'quality'
  const out: string[] = ['-c:v', name]
  switch (plan.encoder) {
    case 'cpu': {
      out.push('-preset', 'medium')
      out.push(...(quality ? ['-crf', q] : rateArgs(plan)))
      if (plan.codec === 'h264') {
        out.push('-profile:v', 'high')
        if (o.pass) out.push('-pass', String(o.pass), '-passlogfile', o.passLogName ?? PASSLOG_NAME)
      } else {
        const p = o.pass ? `pass=${o.pass}:stats=${o.passLogName ?? PASSLOG_NAME}.log:` : ''
        out.push('-x265-params', `${p}log-level=error`)
      }
      break
    }
    case 'nvenc':
      out.push('-preset', 'p5', '-rc', 'vbr')
      if (quality) out.push('-cq', q, '-b:v', '0')
      else out.push(...(plan.mode === 'target' ? ['-multipass', 'fullres'] : []), ...rateArgs(plan))
      break
    case 'amf':
      out.push(...(quality ? ['-rc', 'qvbr', '-qvbr_quality_level', q] : ['-rc', 'vbr_peak', ...rateArgs(plan)]))
      break
    case 'qsv':
      out.push('-preset', 'medium', ...(quality ? ['-global_quality', q] : rateArgs(plan)))
      break
  }
  if (plan.codec === 'h265') out.push('-tag:v', 'hvc1')
  return out
}

export function buildArgs(info: VideoInfo, plan: Plan, o: ArgsOptions): string[] {
  const a: string[] = ['-hide_banner', '-nostdin', '-y', '-progress', 'pipe:1', '-nostats']
  if (o.sample) a.push('-ss', String(o.sample.startSec))
  a.push('-i', o.input)
  if (o.sample) a.push('-t', String(o.sample.durationSec))
  a.push('-map', '0:v:0')
  const withAudio = plan.audioKbps !== null && o.pass !== 1
  if (withAudio) a.push('-map', '0:a:0')
  a.push('-vf', videoFilter(info, plan))
  if (info.hdr) a.push('-color_primaries', 'bt709', '-color_trc', 'bt709', '-colorspace', 'bt709')
  a.push(...encoderArgs(plan, o))
  if (o.pass === 1) {
    a.push('-an', '-f', 'null', 'NUL')
    return a
  }
  a.push(...(withAudio ? ['-c:a', 'aac', '-b:a', `${plan.audioKbps}k`] : ['-an']))
  a.push('-movflags', '+faststart', o.output)
  return a
}
```

```ts
import { execFile } from 'node:child_process'
import { stat } from 'node:fs/promises'
import { promisify } from 'node:util'
import type { VideoInfo } from '@shared/types'

export class ProbeError extends Error {
  constructor(public reason: 'no-video' | 'unreadable', message = reason) { super(message) }
}

interface Stream {
  codec_type?: string; codec_name?: string; width?: number; height?: number
  avg_frame_rate?: string; r_frame_rate?: string; bit_rate?: string; color_transfer?: string
  disposition?: { attached_pic?: number }; side_data_list?: { rotation?: number }[]; tags?: { rotate?: string }
}
interface ProbeJson { format?: { duration?: string; bit_rate?: string }; streams?: Stream[] }

function rate(s: string | undefined): { fps: number; fraction: string } | null {
  if (!s) return null
  const [n, d] = s.split('/').map(Number)
  if (!n || !d) return null
  return { fps: n / d, fraction: `${n}/${d}` }
}

export function parseProbe(json: unknown, path: string, sizeBytes: number): VideoInfo {
  const j = json as ProbeJson
  const streams = j.streams ?? []
  const v = streams.find((s) => s.codec_type === 'video' && s.disposition?.attached_pic !== 1)
  if (!v || !v.width || !v.height) throw new ProbeError('no-video')
  const duration = Number(j.format?.duration)
  if (!Number.isFinite(duration) || duration <= 0) throw new ProbeError('unreadable')
  const r = rate(v.avg_frame_rate) ?? rate(v.r_frame_rate)
  if (!r) throw new ProbeError('unreadable')

  const rotation = Math.abs(v.side_data_list?.find((d) => d.rotation !== undefined)?.rotation ?? Number(v.tags?.rotate ?? 0))
  const swap = rotation % 180 === 90
  const a = streams.find((s) => s.codec_type === 'audio')
  const audioKbps = a?.bit_rate ? Math.round(Number(a.bit_rate) / 1000) : 0
  const totalKbps = j.format?.bit_rate ? Math.round(Number(j.format.bit_rate) / 1000) : 0
  const videoKbps = v.bit_rate ? Math.round(Number(v.bit_rate) / 1000) : Math.max(0, totalKbps - audioKbps)

  return {
    path, sizeBytes, durationSec: duration,
    width: swap ? v.height : v.width, height: swap ? v.width : v.height,
    fps: r.fps, fpsFraction: r.fraction,
    videoCodec: v.codec_name ?? 'unknown', videoKbps,
    hasAudio: Boolean(a), audioCodec: a?.codec_name ?? '', audioKbps,
    hdr: v.color_transfer === 'smpte2084' || v.color_transfer === 'arib-std-b67'
  }
}

const run = promisify(execFile)

export async function probeFile(ffprobe: string, path: string): Promise<VideoInfo> {
  let stdout: string
  try {
    ;({ stdout } = await run(ffprobe, ['-v', 'error', '-print_format', 'json', '-show_format', '-show_streams', path], { windowsHide: true, maxBuffer: 16 * 1024 * 1024 }))
  } catch {
    throw new ProbeError('unreadable')
  }
  const { size } = await stat(path)
  return parseProbe(JSON.parse(stdout), path, size)
}
```

```ts
import { spawn } from 'node:child_process'

export interface RunOptions {
  cwd?: string
  onLine?: (line: string) => void
  onErrLine?: (line: string) => void
  signal?: AbortSignal
}
export interface RunResult { code: number | null; stderrTail: string; aborted: boolean }
export type Runner = (args: string[], opts?: RunOptions) => Promise<RunResult>

function splitter(cb?: (l: string) => void): (chunk: string) => void {
  let buf = ''
  return (chunk) => {
    buf += chunk
    let i: number
    while ((i = buf.search(/\r?\n|\r/)) >= 0) {
      const line = buf.slice(0, i).trim()
      buf = buf.slice(i + (buf[i] === '\r' && buf[i + 1] === '\n' ? 2 : 1))
      if (line) cb?.(line)
    }
  }
}

export function createRunner(binary: string): Runner {
  return (args, opts = {}) => new Promise((resolve) => {
    let tail = ''
    let aborted = false
    let done = false
    const finish = (code: number | null): void => {
      if (done) return
      done = true
      opts.signal?.removeEventListener('abort', onAbort)
      resolve({ code, stderrTail: tail, aborted })
    }
    const child = spawn(binary, args, { cwd: opts.cwd, windowsHide: true })
    function onAbort(): void { aborted = true; child.kill() }
    if (opts.signal?.aborted) onAbort()
    else opts.signal?.addEventListener('abort', onAbort, { once: true })
    const out = splitter(opts.onLine)
    const err = splitter(opts.onErrLine)
    child.stdout?.setEncoding('utf8').on('data', out)
    child.stderr?.setEncoding('utf8').on('data', (d: string) => { tail = (tail + d).slice(-8000); err(d) })
    child.on('error', (e) => { tail += String(e); finish(-1) })
    child.on('close', (code) => finish(code))
  })
}
```

```ts
export interface ProgressState { outTimeSec: number; speed: number | null; ended: boolean }

export function applyProgressLine(state: ProgressState, line: string): ProgressState {
  const i = line.indexOf('=')
  if (i < 0) return state
  const key = line.slice(0, i)
  const value = line.slice(i + 1).trim()
  if (key === 'out_time_us') {
    const us = Number(value)
    return Number.isFinite(us) ? { ...state, outTimeSec: us / 1e6 } : state
  }
  if (key === 'speed') {
    const sp = Number(value.replace('x', ''))
    return Number.isFinite(sp) && value !== 'N/A' ? { ...state, speed: sp } : state
  }
  if (key === 'progress' && value === 'end') return { ...state, ended: true }
  return state
}
```

```ts
  req: EncodeRequest,
  deps: EncodeDeps,
  on: { progress?: (p: EncodeProgress) => void; log?: (line: string) => void },
  signal?: AbortSignal
): Promise<EncodeResult> {
  const { info, settings, available, output } = req
  const cleanPasslogs = async (): Promise<void> => {
    for (const f of PASSLOGS) await deps.remove(win32.join(deps.tmpDir, f))
  }

  async function encodeOnce(plan: Plan): Promise<Once> {
    for (let pass = 1; pass <= plan.passes; pass++) {
      let st: ProgressState = { outTimeSec: 0, speed: null, ended: false }
      const args = buildArgs(info, plan, {
        input: info.path, output,
        pass: plan.passes === 2 ? (pass as 1 | 2) : undefined,
        passLogName: PASSLOG_NAME
      })
      on.log?.(`> ffmpeg ${args.join(' ')}`)
      const r = await deps.run(args, {
        cwd: deps.tmpDir, signal, onErrLine: on.log,
        onLine: (line) => {
          st = applyProgressLine(st, line)
          const within = Math.min(1, st.outTimeSec / info.durationSec)
          const fraction = (pass - 1 + within) / plan.passes
          const remainingSec = st.speed ? ((1 - fraction) * info.durationSec * plan.passes) / st.speed : null
          on.progress?.({ fraction, pass, passes: plan.passes, speed: st.speed, remainingSec, encoder: plan.encoder })
        }
      })
      if (r.aborted || signal?.aborted) {
        await deps.remove(output); await cleanPasslogs()
        throw new EncodeError('aborted', 'Cancelled')
      }
      if (r.code !== 0) {
        await deps.remove(output); await cleanPasslogs()
        if (DISK_FULL.test(r.stderrTail)) throw new EncodeError('disk', `Not enough disk space to write ${output}`, r.stderrTail)
        return { ok: false, log: r.stderrTail }
      }
    }
    await cleanPasslogs()
    return { ok: true }
  }

  let encoder = buildPlan(info, settings, available).encoder
  let videoKbps: number | undefined
  let fellBack = false
  let retries = 0
  let attempts = 0
  const limit = settings.maxMB !== null ? settings.maxMB * 1e6 : Infinity

  for (;;) {
    const plan = buildPlan(info, settings, available, { encoder, videoKbps })
    attempts++
    const r = await encodeOnce(plan)
    if (!r.ok) {
      if (encoder !== 'cpu') { encoder = 'cpu'; fellBack = true; retries = 0; continue }
      throw new EncodeError('ffmpeg', 'FFmpeg stopped with an error.', r.log)
    }
    const bytes = await deps.fileSize(output)
    if (bytes <= limit) return { output, bytes, encoder, fellBack, attempts }
    const lower = Math.max(MIN_VIDEO_KBPS, Math.floor(plan.videoKbps * (limit / bytes) * 0.98))
    if (retries < 2) { retries++; videoKbps = lower; continue }
    if (encoder !== 'cpu') { encoder = 'cpu'; retries = 0; videoKbps = lower; continue }
    await deps.remove(output)
    throw new EncodeError('size', `Could not get this video under ${settings.maxMB} MB.`)
  }
}
```

```ts
import { win32 } from 'node:path'
import { buildArgs, TONEMAP_CHAIN } from '@shared/ffmpegArgs'
import { buildPlan } from '@shared/planner'
import type { EncoderId, Settings, VideoInfo } from '@shared/types'
import type { Runner } from '../ffmpeg/runner'

export function sampleWindow(info: VideoInfo): { startSec: number; durationSec: number } {
  const durationSec = Math.min(5, info.durationSec)
  return { startSec: Math.max(0, info.durationSec / 2 - durationSec / 2), durationSec }
}

const sdr = (info: VideoInfo, extra: string[] = []): string => [...(info.hdr ? TONEMAP_CHAIN : []), ...extra, 'format=yuv420p'].join(',')

export async function makeThumbnail(run: Runner, info: VideoInfo, outFile: string): Promise<boolean> {
  const r = await run(['-hide_banner', '-nostdin', '-y', '-ss', String(info.durationSec * 0.1), '-i', info.path,
    '-frames:v', '1', '-vf', sdr(info, ['scale=-2:540']), '-q:v', '3', outFile])
  return r.code === 0
}

let counter = 0

export async function makePreview(
  run: Runner, req: { info: VideoInfo; settings: Settings; available: EncoderId[] }, dir: string, signal?: AbortSignal
): Promise<{ before: string; after: string }> {
  const { info } = req
  const n = ++counter
  const win = sampleWindow(info)
  const before = `before-${n}.mp4`
  const after = `after-${n}.mp4`
  const raw = win32.join(dir, `after-raw-${n}.mp4`)
  const display = (inFile: string, vf: string, outFile: string): string[] =>
    ['-hide_banner', '-nostdin', '-y', '-ss', String(win.startSec), '-i', inFile, '-t', String(win.durationSec),
      '-map', '0:v:0', '-an', '-vf', vf, '-c:v', 'libx264', '-preset', 'ultrafast', '-crf', '12', win32.join(dir, outFile)]

  const b = await run(display(info.path, sdr(info), before), { signal })
  if (b.code !== 0) throw new Error('Preview failed (before).')

  const encodeAfter = async (encoder?: EncoderId): Promise<{ ok: boolean; codec: string }> => {
    const base = buildPlan(info, req.settings, req.available, encoder ? { encoder } : {})
    const plan = { ...base, passes: 1 as const }
    const args = buildArgs(info, plan, { input: info.path, output: raw, sample: win })
    const r = await run(args, { signal })
    return { ok: r.code === 0, codec: plan.codec }
  }
  let a = await encodeAfter()
  if (!a.ok) a = await encodeAfter('cpu')
  if (!a.ok) throw new Error('Preview failed (after).')

  const final = win32.join(dir, after)
  const conv = await run(['-hide_banner', '-nostdin', '-y', '-i', raw, '-map', '0:v:0', '-an',
    '-c:v', 'libx264', '-preset', 'ultrafast', '-crf', '12', final], { signal })
  if (conv.code !== 0) throw new Error('Preview failed (display copy).')
  return { before, after }
}
```

This always writes an H.264 display copy, for both codecs. That keeps the renderer's `<video>` independent of H.265 support in Chromium, and CRF 12 is visually lossless over the compressed result. The test expects 3 calls for H.265. H.264 also makes 3 calls.

```ts
import { dirname } from 'node:path'
import { DEFAULT_PRESET_ID } from '@shared/presets'
import type { Preset, PresetSettings, StoreData } from '@shared/types'

export function defaultStore(): StoreData {
  return { version: 1, userPresets: [], lastPresetId: DEFAULT_PRESET_ID, promoDismissed: false }
}

export async function loadStore(file: string): Promise<StoreData> {
  try {
    const d = JSON.parse(await readFile(file, 'utf8')) as Partial<StoreData>
    if (d.version !== 1 || !Array.isArray(d.userPresets)) return defaultStore()
    return {
      version: 1,
      userPresets: d.userPresets.filter((p) => p && typeof p.id === 'string' && typeof p.label === 'string' && p.settings),
      lastPresetId: typeof d.lastPresetId === 'string' ? d.lastPresetId : DEFAULT_PRESET_ID,
      promoDismissed: d.promoDismissed === true
    }
  } catch {
    return defaultStore()
  }
}

export async function saveStore(file: string, d: StoreData): Promise<void> {
  await mkdir(dirname(file), { recursive: true })
  const tmp = `${file}.tmp`
  await writeFile(tmp, JSON.stringify(d, null, 2), 'utf8')
  await rename(tmp, file)
}

export function cleanLabel(label: string): string | null {
  const t = label.trim().slice(0, 40)
  return t.length ? t : null
}

export function addPreset(d: StoreData, label: string, settings: PresetSettings, now: number): { data: StoreData; preset: Preset } {
  const preset: Preset = { id: `user-${now}`, label: cleanLabel(label) ?? 'My preset', builtIn: false, settings }
  return { preset, data: { ...d, userPresets: [...d.userPresets, preset], lastPresetId: preset.id } }
}

export function renamePreset(d: StoreData, id: string, label: string): StoreData {
  const l = cleanLabel(label)
  if (!l) return d
  return { ...d, userPresets: d.userPresets.map((p) => (p.id === id ? { ...p, label: l } : p)) }
}

export function deletePreset(d: StoreData, id: string): StoreData {
  return {
    ...d,
    userPresets: d.userPresets.filter((p) => p.id !== id),
    lastPresetId: d.lastPresetId === id ? DEFAULT_PRESET_ID : d.lastPresetId
  }
}
```

```ts
import { BUILT_IN_PRESETS } from '@shared/presets'
import type { EncoderChoice, Preset, Settings, StoreData, VideoInfo } from '@shared/types'

  return [...BUILT_IN_PRESETS, ...d.userPresets]

export function settingsFromPreset(p: Preset, encoder: EncoderChoice): Settings {
  return { ...p.settings, encoder }
}

export function doneSummary(info: VideoInfo, maxMB: number | null, bytes: number): string {
  const pct = Math.round((1 - bytes / info.sizeBytes) * 100)
  const smaller = pct > 0 ? `${pct}% smaller than before.` : 'Slightly larger than the original. The source was already well compressed.'
  if (maxMB === null) return smaller
  const spare = (maxMB * 1e6 - bytes) / 1e6
  return `Fits under ${maxMB} MB with ${spare.toFixed(1)} MB to spare. ${smaller}`
}

export function nextPresetName(d: StoreData): string {
  const taken = new Set(d.userPresets.map((p) => p.label))
  for (let n = 1; ; n++) if (!taken.has(`My preset ${n}`)) return `My preset ${n}`
}
```

```ts
import type { EncoderId, PresetSettings, Settings, StoreData, VideoInfo } from '@shared/types'

import { probeFile } from './ffmpeg/probe'
import { createRunner } from './ffmpeg/runner'
import { uniqueOutputPath } from './encode/output'
import { makePreview, makeThumbnail } from './encode/preview'
import { EncodeError, runEncode } from './encode/runEncode'
import { mediaUrl } from './media'
import { addPreset, deletePreset, loadStore, renamePreset, saveStore } from './store/presetStore'

export interface IpcEnv { ffmpeg: string; ffprobe: string; tmpDir: string; mediaDir: string; storeFile: string }

export function registerIpc(env: IpcEnv, getWindow: () => BrowserWindow | null): void {
  const run = createRunner(env.ffmpeg)
  const encodersP: Promise<EncoderId[]> = detectEncoders(run).catch(() => ['cpu'])
  let info: VideoInfo | null = null
  let job: AbortController | null = null
  let store: StoreData | null = null
  const getStore = async (): Promise<StoreData> => (store ??= await loadStore(env.storeFile))
  const setStore = async (d: StoreData): Promise<StoreData> => { store = d; await saveStore(env.storeFile, d); return d }
  const send = (ch: string, payload: unknown): void => getWindow()?.webContents.send(ch, payload)

  ipcMain.handle('file:open', async () => {
    const w = getWindow()
    const r = await dialog.showOpenDialog(w!, { properties: ['openFile'], filters: [{ name: 'Video', extensions: ['mp4', 'mov', 'mkv', 'webm', 'avi', 'm4v', 'mts', 'm2ts', 'wmv'] }] })
    return r.canceled ? null : r.filePaths[0]
  })

  ipcMain.handle('probe', async (_e, path: string): Promise<ProbeResult> => {
    try {
      info = await probeFile(env.ffprobe, path)
      await mkdir(env.mediaDir, { recursive: true })
      const thumb = `thumb-${Date.now()}.jpg`
      const ok = await makeThumbnail(run, info, join(env.mediaDir, thumb))
      return { ok: true, info, thumbUrl: ok ? mediaUrl(thumb) : null }
    } catch {
      info = null
      return { ok: false, message: "Can't read this file." }
    }
  })

  ipcMain.handle('encoders', () => encodersP)

  ipcMain.handle('preview', async (_e, settings: Settings): Promise<PreviewResult> => {
    if (!info) return { ok: false, message: 'No video loaded.' }
    try {
      await mkdir(env.mediaDir, { recursive: true })
      const r = await makePreview(run, { info, settings, available: await encodersP }, env.mediaDir)
      return { ok: true, beforeUrl: mediaUrl(r.before), afterUrl: mediaUrl(r.after) }
    } catch (e) {
      return { ok: false, message: (e as Error).message }
    }
  })

  ipcMain.handle('encode', async (_e, settings: Settings): Promise<EncodeOutcome> => {
    if (!info) return { ok: false, kind: 'ffmpeg', message: 'No video loaded.', log: '' }
    job = new AbortController()
    await mkdir(env.tmpDir, { recursive: true })
    const output = uniqueOutputPath(info.path, existsSync)
    try {
      const result = await runEncode(
        { info, settings, available: await encodersP, output },
        { run, tmpDir: env.tmpDir, fileSize: async (p) => (await stat(p)).size, remove: (p) => unlink(p).catch(() => {}) },
        { progress: (p) => send('encode:progress', p), log: (l) => send('encode:log', l) },
        job.signal
      )
      return { ok: true, result }
    } catch (e) {
      if (e instanceof EncodeError) return { ok: false, kind: e.kind, message: e.message, log: e.log }
      return { ok: false, kind: 'ffmpeg', message: (e as Error).message, log: '' }
    } finally {
      job = null
    }
  })

  ipcMain.handle('cancel', () => { job?.abort() })

  ipcMain.handle('store:get', () => getStore())
  ipcMain.handle('store:add', async (_e, label: string, s: PresetSettings) => setStore(addPreset(await getStore(), label, s, Date.now()).data))
  ipcMain.handle('store:rename', async (_e, id: string, label: string) => setStore(renamePreset(await getStore(), id, label)))
  ipcMain.handle('store:delete', async (_e, id: string) => setStore(deletePreset(await getStore(), id)))
  ipcMain.handle('store:last', async (_e, id: string) => setStore({ ...(await getStore()), lastPresetId: id }))
  ipcMain.handle('store:dismissPromo', async () => setStore({ ...(await getStore()), promoDismissed: true }))

  ipcMain.handle('reveal', (_e, p: string) => { shell.showItemInFolder(p) })
  ipcMain.handle('open:promo', () => shell.openExternal(PROMO_URL))
  ipcMain.handle('open:ffmpeg', () => shell.openExternal(FFMPEG_SOURCE_URL))

  ipcMain.on('app:version', (e) => { e.returnValue = app.getVersion() })
  ipcMain.on('win:minimize', () => getWindow()?.minimize())
  ipcMain.on('win:toggleMaximize', () => { const w = getWindow(); if (w) w.isMaximized() ? w.unmaximize() : w.maximize() })
  ipcMain.on('win:close', () => getWindow()?.close())
}

export async function cleanupTemp(dir: string): Promise<void> {
  await rm(dir, { recursive: true, force: true })
}
```

```ts
import { create } from 'zustand'
import { buildPlan } from '@shared/planner'
import { BUILT_IN_PRESETS, DEFAULT_PRESET_ID } from '@shared/presets'
import type { EncodeProgress, EncodeResult, EncoderId, Plan, Settings, StoreData, VideoInfo } from '@shared/types'
import { allPresets, settingsFromPreset } from './logic'

export type Screen = 'drop' | 'settings' | 'compare' | 'encoding' | 'done'

interface State {
  screen: Screen
  info: VideoInfo | null
  thumbUrl: string | null
  available: EncoderId[] | null
  data: StoreData | null
  presetId: string
  settings: Settings
  edited: boolean
  plan: Plan | null
  dropError: string | null
  dropNonce: number
  progress: EncodeProgress | null
  log: string[]
  result: EncodeResult | null
  encodeError: { kind: string; message: string; log: string } | null
  preview: { beforeUrl: string; afterUrl: string } | null
  previewError: string | null
  init(): Promise<void>
  openFile(path: string): Promise<void>
  pickPreset(id: string): void
  edit(patch: Partial<Settings>): void
  savePreset(label: string): Promise<void>
  renamePreset(id: string, label: string): Promise<void>
  deletePreset(id: string): Promise<void>
  loadPreview(): Promise<void>
  startEncode(): Promise<void>
  cancelEncode(): Promise<void>
  backToSettings(): void
  reset(): void
  dismissPromo(): Promise<void>
}

const api = (): Window['squish'] => window.squish
const initialSettings = settingsFromPreset(BUILT_IN_PRESETS[0], 'auto')

export const useSquish = create<State>((set, get) => {
  const replan = (settings: Settings): Plan | null => {
    const { info, available } = get()
    return info ? buildPlan(info, settings, available ?? ['cpu']) : null
  }
  const applyPreset = (id: string, data: StoreData): void => {
    const p = allPresets(data).find((x) => x.id === id) ?? BUILT_IN_PRESETS[0]
    const settings = settingsFromPreset(p, get().settings.encoder)
    set({ presetId: p.id, settings, edited: false, plan: replan(settings) })
  }

  return {
    screen: 'drop', info: null, thumbUrl: null, available: null, data: null,
    presetId: DEFAULT_PRESET_ID, settings: initialSettings, edited: false, plan: null,
    dropError: null, dropNonce: 0, progress: null, log: [], result: null, encodeError: null,
    preview: null, previewError: null,

    async init() {
      const data = await api().store.get()
      set({ data })
      applyPreset(data.lastPresetId, data)
      api().encoders().then((available) => set({ available, plan: replan(get().settings) }))
      api().onProgress((progress) => set({ progress }))
      api().onLog((line) => set((s) => ({ log: [...s.log.slice(-299), line] })))
    },

    async openFile(path) {
      const r = await api().probe(path)
      if (!r.ok) { set((s) => ({ dropError: r.message, dropNonce: s.dropNonce + 1 })); return }
      set({ info: r.info, thumbUrl: r.thumbUrl, dropError: null, preview: null, screen: 'settings' })
      set({ plan: replan(get().settings) })
    },

    pickPreset(id) {
      const data = get().data
      if (!data) return
      applyPreset(id, data)
      api().store.setLastPreset(id).then((d) => set({ data: d }))
    },

    edit(patch) {
      const settings = { ...get().settings, ...patch }
      set({ settings, edited: true, plan: replan(settings), preview: null })
    },

    async savePreset(label) {
      const { encoder: _encoder, ...rest } = get().settings
      const data = await api().store.addPreset(label, rest)
      set({ data, presetId: data.lastPresetId, edited: false })
    },
    async renamePreset(id, label) { set({ data: await api().store.renamePreset(id, label) }) },
    async deletePreset(id) {
      const data = await api().store.deletePreset(id)
      set({ data })
      if (get().presetId === id) applyPreset(data.lastPresetId, data)
    },

    async loadPreview() {
      set({ screen: 'compare', preview: null, previewError: null })
      const r = await api().preview(get().settings)
      if (r.ok) set({ preview: { beforeUrl: r.beforeUrl, afterUrl: r.afterUrl } })
      else set({ previewError: r.message })
    },

    async startEncode() {
      set({ screen: 'encoding', progress: null, log: [], encodeError: null, result: null })
      const r = await api().encode(get().settings)
      if (r.ok) set({ result: r.result, screen: 'done' })
      else if (r.kind === 'aborted') set({ screen: 'settings' })
      else set({ encodeError: { kind: r.kind, message: r.message, log: r.log } })
```

```tsx
          <motion.h1 className="display" initial={{ opacity: 0, y: 16, filter: 'blur(6px)' }} animate={{ opacity: 1, y: 0, filter: 'blur(0px)' }} transition={{ ...smooth, delay: 0.56 }}
            style={{ margin: 0, fontSize: 76, lineHeight: '76px', letterSpacing: '-0.02em', fontVariantNumeric: 'tabular-nums' }}>
            Done. <motion.span>{text}</motion.span>.
          </motion.h1>
          <motion.p initial={{ opacity: 0, y: 16 }} animate={{ opacity: 1, y: 0 }} transition={{ ...smooth, delay: 0.64 }} style={{ margin: 0, fontSize: 19, lineHeight: '30px', color: 'var(--ink-2)' }}>
            {doneSummary(info, settings.maxMB, result.bytes)}
          </motion.p>
          {result.fellBack && <p className="mono" style={{ margin: 0, fontSize: 13, color: 'var(--ink-3)' }}>Your GPU encoder failed, finished on CPU.</p>}
        </div>
        <motion.div initial={{ opacity: 0, y: 16 }} animate={{ opacity: 1, y: 0 }} transition={{ ...smooth, delay: 0.72 }} style={{ display: 'flex', gap: 8 }}>
          <motion.button {...pressProps} className="btn btn-gold" onClick={() => void window.squish.revealInFolder(result.output)}>Show in folder</motion.button>
          <motion.button {...pressProps} className="btn btn-ghost" onClick={reset}>Squish another</motion.button>
        </motion.div>
      </div>
      {data && !data.promoDismissed && (
        <div style={{ flexShrink: 0, margin: '0 32px', height: 56, overflow: 'hidden', borderTop: '1px solid var(--hairline)' }}>
          <motion.div initial={{ y: '100%', opacity: 0 }} animate={{ y: 0, opacity: 1 }} transition={{ ...smooth, delay: 1.5 }}
            style={{ height: 56, display: 'flex', alignItems: 'center', justifyContent: 'space-between' }}>
            <span style={{ fontSize: 14, color: 'var(--ink-3)' }}>
              Squish is free. Pyno's makes more tools for editors.{' '}
              <button className="link-btn" onClick={() => void window.squish.openPromo()}>See them →</button>
            </span>
            <button aria-label="Hide this" className="mono" style={{ width: 32, height: 32, color: 'var(--ink-3)', fontSize: 16 }} onClick={() => void dismissPromo()}>×</button>
          </motion.div>
        </div>
      )}
    </div>
  )
}
```
